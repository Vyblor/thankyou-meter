## 정한 것

- **화면.** Kotlin과 Jetpack Compose로 만든다. 빌드 설정은 카플래시와 같다: AGP 8.5.0, Kotlin 1.9.24, Compose BOM 2024.06.00, compileSdk 34, minSdk 28.
- **해치.** WebView 3D를 쓰지 않고 포즈 PNG를 쓴다. 땡큐미터는 주행 중 화면이 없고 P단 화면에서 표정만 바꾸면 되므로 PNG로 충분하다(`INFERRED`).
- **차량 신호.**
  - Pleos Vehicle SDK 2.3.2: 방향지시등(`registerTurnSignalState`), 조향각(`registerSteeringWheelAngle`), 기어(`registerGearSelection`).
  - AAOS: 속도(`PERF_VEHICLE_SPEED`, m/s).
  - 수신은 포그라운드 서비스(specialUse)에서 한다. 앱 화면이 뒤에 있어도 받는다(`EXTRACTED`, 2026-11-05).
- **음성.**
  - Pleos TextToSpeech와 SpeechToText 3.3.1 ON_DEVICE를 쓴다. 질문 앞뒤 알림음은 앱이 직접 합성한다.
  - 합성 음성은 STT가 알아듣지 못했다(0/10). 그래서 e2e 시험은 디버그 빌드 전용 방송으로 "인식된 글자"를 넣는다. 실제 경로(TTS 말하기, STT 듣기 시작)가 불렸는지는 로그로 확인한다.
- **저장.**
  - 서버 없이 기기 안 JSON 파일에만 쌓는다.
  - 동네 순위와 다른 동네 값은 목업이다.
  - 시군구는 위치 권한 없이 설정의 "우리 동네"(기본 성동구)를 쓴다(목업).
- **주행 중 화면 없음.** `distractionOptimized`를 선언하지 않는다. D단에서는 시스템이 앱을 막고 서비스만 돈다.
- **테마.** 시스템 낮·밤(uiMode)을 따른다. 디자인 토큰 `tokens.css`를 그대로 옮긴다.
- **커밋 신원.** `Haechi <225294644+Vyblor@users.noreply.github.com>`. 스프린트가 통과할 때마다 커밋하고 `origin`(`Vyblor/thankyou-meter`, 비공개)에 푸시한다. 공동창업자가 그렇게 지시했다.

## E2E 시험 방식

에뮬레이터(Pleos Connect v2.1.0, AVD `Pleos_Probe`)에 디버그 APK를 설치한다. `e2e/`의 Python 스크립트가 세 경로로 시험한다.

- **화면.** adb로 조작하고, Compose `testTag`를 resource-id로 내보내 `uiautomator dump`로 찾는다(카플래시와 같은 방식).
- **차 신호.** 버추얼 콘솔 HTTP 8088로 보낸다: `/vehicle/gear`, `/vehicle/turn-signal`, `/vehicle/controls?speed&steering`.
- **판정.** 앱 로그(`TYM` 태그)로 한다.

스프린트마다 시험 스크립트 하나(`e2e/sN_*.py`)를 쓴다. 다음 스프린트에서는 앞 시험도 다시 돌린다.

### S1 — 통과 (2026-11-07)

**만든 것.**

- Gradle 프로젝트를 세웠다. Pleos 의존성은 Vehicle 2.3.2, SpeechToText 3.3.1, TextToSpeech 3.3.1이다.
- 디자인 토큰을 `ui/theme/Theme.kt`에 옮겼다(낮·밤 두 벌, 로즈 하트 `#E8365F`/`#FF7A98`).
- 공통 컴포넌트는 `ui/components/Components.kt`에 있다: 버튼, 아이콘 버튼, 기어 칩, 머리, 레일, 아래 탭, 두 숫자 카드, 작은 숫자, 기록 줄, 띠, 스위치 줄, 세그먼트, 토스트, 팝업, 스텝퍼, 해치, 말풍선.
- 첫 실행 A1~A4를 만들었다. A3는 마이크 권한을 요청한다. A4 목소리 시험은 세 번 중 두 번 들리면 통과한다. 두 번 못 들으면 "아무 말이나 예로 듣기"를 제안한다.
- 홈 C1(A5 준비 끝 포함)을 만들었다.
- 기록 저장소 `data/Store.kt`는 기기 안 JSON 파일 하나다.
- 차량 신호 게이트웨이 `vehicle/Signals.kt`와 음성 계층 `voice/Voice.kt`(TTS, STT, 합성 알림음, 대답 분류)를 만들었다.

**시험 결과.** `e2e/s1_onboard_home.py` 29개 항목이 모두 PASS다. 두 번 연속 돌려 두 번 다 통과했다(에뮬레이터 Pleos_Probe, 2026-11-07). `EXTRACTED`

**시험 중 고친 것.**

- 실제 버그 1건을 고쳤다. 앞 듣기를 멈춘 뒤 STT 종료 이벤트가 늦게 오면, 다음 듣기가 "못 들음"으로 끝날 수 있었다. 이제 이번 요청의 시작 이벤트를 본 뒤에만 종료를 받는다.
- 시험 쪽 버그 2건을 고쳤다.
  - 화면 읽기(약 2초) 때문에 4초 듣기 창을 놓쳤다. 시험이 "듣기 시작" 로그를 기다린 뒤 말하게 바꿨다.
  - 바탕색을 시스템 바 위치에서 읽었다. 앱 바탕 위치로 옮겼다.

**알게 된 것.**

- `EXTRACTED` 에뮬레이터에서 STT `request()` 뒤 `onStartedRecognition`이 오지 않는다. 마이크 입력이 없어서로 보인다(`INFERRED`). 실제 인식은 수동 시험에서 사람 목소리로 본다.
- `AMBIGUOUS` TTS 음량을 바꾸는 API는 문서에 없다. 설정의 목소리 크기는 알림음에만 적용한다.

### S2 — 통과 (2026-11-07)

**만든 것.**

- `detect/Detector.kt`는 감지 규칙만 담은 순수 로직이다. 시각을 신호와 tick으로만 받아서 JVM 단위 시험이 가능하다. 판정하는 것은 다음과 같다.
  - 차선 변경: 조향 5도 넘음 → 반대로 3도 되돌림 → 3도 안에서 3초.
  - 회전 제외(90도 초과), 저속 제외(평균 30 km/h 미만), D단만.
  - 깜빡이만 켠 경우는 취소한다.
  - 깜빡이 없는 차선 변경은 통계에만 넣는다.
  - 급한 차선 변경: 0.5초 안에 40도.
  - 양보 후보: 30 km/h 이상에서 5초 안에 10 km/h 이상 감속하고, 10 km/h 아래로는 내려가지 않고, 20초 안에 5 km/h 다시 가속.

**시험 중 고친 것.**

- 버그 1. 감속 시작점으로 "최근 5초 최대값"의 가장 오래된 표본을 골랐다. 그래서 일정 속도로 달린 뒤 감속하면 시작점이 늘 5초보다 오래돼 후보가 0이었다. 이제 가장 최근의 최대값 표본을 고른다(단위 시험에서 발견).
- 버그 2. 값이 그대로면 속도 신호가 드물게 온다. 그래서 0.5초마다 지금 속도를 이력에 넣는다.
- 버그 3. `CAR_SPEED`는 런타임 권한인데 요청하지 않았다. 운전자 사용자(10)에게 권한이 없어 속도가 한 번도 오지 않았다. 이제 A3에서 요청하고, 권한을 받으면 다시 등록한다.
- 버그 4. 에뮬레이터의 원터치(FlashLeft)는 LEFT만 보내고 OFF를 보내지 않는다. 그래서 두 번째 원터치부터는 새 깜빡임으로 보지 않았다. 이제 지금 켜져 있으면 깜빡이를 켠 것으로 본다.
- 시험 쪽 1건. 회전 시험이 60에서 25 km/h로 순간 이동해 급제동으로 집계됐다. 시험이 천천히 줄이게 바꿨다.

**알게 된 것.**

- `EXTRACTED` 콘솔 `controls?speed=`는 AAOS `PERF_VEHICLE_SPEED`로 그대로 온다. 단, 앱에 `CAR_SPEED` 런타임 권한이 있어야 한다.
- `EXTRACTED` 에뮬레이터 원터치는 꺼짐 이벤트가 오지 않는다. 실차에서 원터치가 3회 깜빡인 뒤 OFF를 보내는지는 `AMBIGUOUS`다.
- `EXTRACTED` 앱 화면이 뒤에 있어도 서비스가 신호를 받아 감지했다(포그라운드 형식 special+mic로 시작됨).

### S3 — 통과 (2026-11-07)

**만든 것.** `detect/Asker.kt`가 와이어프레임 B3~B5의 소리 흐름을 맡는다.

- 깜빡이를 켠 차선 변경이 끝나면 6초 뒤로 질문을 예약한다. 질문할 때 D단인지 다시 보고, 오디오 포커스(TRANSIENT_MAY_DUCK)를 받지 못하면 묻지 않는다.
- 질문 순서: 띵(150ms) → "양보받았어요?" → 4초 듣기.
- 대답별 처리:
  - 예: 받은 기록을 남기고 "기록했어요"와 두 음을 낸다.
  - "아니": 회색 기록을 남기고 한 음 하강만 낸다.
  - "오늘은 그만": 그날 쉬고 "오늘은 그만 물을게요"라고 한다.
  - 무응답: 소리도 기록도 없다. 3번 연속이면 그날 쉰다.
- 묻지 않는 경우: 질문 꺼짐, 마이크 권한 없음, 쉬는 날, 하루 상한, 간격 180초 안, 이미 묻는 중.
- 디버그 방송을 늘렸다: `daily_max`, `ask_enabled`.
- 속도 신호의 시각을 이벤트가 생긴 시각(`CarPropertyValue.timestamp`)으로 바꿨다. 빌드 부하로 이벤트가 몰려 도착했을 때 급제동이 1건 더 잡힌 일이 있었기 때문이다.

**시험 결과.** `e2e/s3_voice.py` 24개 항목이 모두 PASS다. S2(전체 횟수)와 S1을 다시 돌려 둘 다 통과했다(2026-11-07, 앱 화면 뒤로, 서비스만으로). `EXTRACTED`

**시험 중 고친 것.**

- 시험 쪽 1건. 순서 검사가 첫 실행 A4의 듣기 로그를 집었다. 이제 질문 로그 뒤부터 찾는다.

**남은 것.**

- `AMBIGUOUS` 실제 STT 인식률은 에뮬레이터에서 볼 수 없다(마이크 입력 없음). 수동 시험에서 사람 목소리로 확인한다.

## 수동 시험에서 볼 것

에뮬레이터 e2e로는 확인할 수 없는 것들이다.

- **실제 목소리 인식(`AMBIGUOUS`).** e2e는 디버그 방송으로 "인식된 글자"를 넣었다. A4 목소리 시험과 주행 중 질문에 사람이 직접 "고마워", "아니", "오늘은 그만"이라고 말해 본다. 에뮬레이터에 맥 마이크를 연결해야 한다(Extended controls → Microphone, "Virtual microphone uses host audio input"). 이것은 일반 안드로이드 에뮬레이터 기능이고, Pleos 이미지에서 되는지는 확인하지 않았다(`INFERRED`).
- **TTS 소리.** "양보받았어요?"·"기록했어요"가 들리는지, 띵·두 음·하강음의 크기와 질문 목소리 설정(작게·보통·크게)을 귀로 본다.
- **주행 중 화면 막힘.** D단에서 앱을 열면 시스템이 막는지(X1), 그동안 질문이 소리로 계속 오는지 본다.
- **버추얼 콘솔 신호.** 브라우저 콘솔(http://127.0.0.1:8088)에서 손으로 깜빡이·조향·속도를 넣는다. 시나리오 값은 위 시험 스크립트에 있다.
- **시연용 예시 기록.** 설정 → "시연용 예시 기록 넣기"를 누르면 지난 날짜에 기록이 들어가 카드·기록 탭을 보기 좋다.
