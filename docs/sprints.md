## 정한 것

- **화면.** Kotlin과 Jetpack Compose로 만든다. 빌드 설정은 카플래시와 같다: AGP 8.5.0, Kotlin 1.9.24, Compose BOM 2024.06.00, compileSdk 34, minSdk 28.
- **해치.** WebView 3D를 쓰지 않고 포즈 PNG를 쓴다. 땡큐미터는 주행 중 화면이 없고 P단 화면에서 표정만 바꾸면 되므로 PNG로 충분하다(`INFERRED`).
- **차량 신호.**
  - Pleos Vehicle SDK 2.3.2: 방향지시등(`registerTurnSignalState`), 조향각(`registerSteeringWheelAngle`), 기어(`registerGearSelection`).
  - AAOS: 속도(`PERF_VEHICLE_SPEED`, m/s).
  - 수신은 포그라운드 서비스(specialUse)에서 한다. 앱 화면이 뒤에 있어도 받는다(`EXTRACTED`, 2026-11-05).
- **음성.**
  - Pleos TextToSpeech와 SpeechToText 3.3.1 ON_DEVICE를 쓴다. 질문 앞뒤 알림음은 앱이 직접 합성한다.
  - 합성 음성은 STT가 알아듣지 못했다(0/10). 그래서 e2e 시험은 디버그 빌드 전용 방송으로 "인식된 글자"를 넣는다. 실제 경로(TTS 말하기, STT 듣기 시작)가 불렸는지는 로그로 확인한다.
- **저장.**
  - 서버 없이 기기 안 JSON 파일에만 쌓는다.
  - 동네 순위와 다른 동네 값은 목업이다.
  - 시군구는 위치 권한 없이 설정의 "우리 동네"(기본 성동구)를 쓴다(목업).
- **주행 중 화면 없음.** `distractionOptimized`를 선언하지 않는다. D단에서는 시스템이 앱을 막고 서비스만 돈다.
- **테마.** 시스템 낮·밤(uiMode)을 따른다. 디자인 토큰 `tokens.css`를 그대로 옮긴다.
- **커밋 신원.** `Haechi <225294644+Vyblor@users.noreply.github.com>`. 스프린트가 통과할 때마다 커밋하고 `origin`(`Vyblor/thankyou-meter`, 비공개)에 푸시한다. 공동창업자가 그렇게 지시했다.

## E2E 시험 방식

에뮬레이터(Pleos Connect v2.1.0, AVD `Pleos_Probe`)에 디버그 APK를 설치한다. `e2e/`의 Python 스크립트가 세 경로로 시험한다.

- **화면.** adb로 조작하고, Compose `testTag`를 resource-id로 내보내 `uiautomator dump`로 찾는다(카플래시와 같은 방식).
- **차 신호.** 버추얼 콘솔 HTTP 8088로 보낸다: `/vehicle/gear`, `/vehicle/turn-signal`, `/vehicle/controls?speed&steering`.
- **판정.** 앱 로그(`TYM` 태그)로 한다.

스프린트마다 시험 스크립트 하나(`e2e/sN_*.py`)를 쓴다. 다음 스프린트에서는 앞 시험도 다시 돌린다.

### S1 — 통과 (2026-11-07)

**만든 것.**

- Gradle 프로젝트를 세웠다. Pleos 의존성은 Vehicle 2.3.2, SpeechToText 3.3.1, TextToSpeech 3.3.1이다.
- 디자인 토큰을 `ui/theme/Theme.kt`에 옮겼다(낮·밤 두 벌, 로즈 하트 `#E8365F`/`#FF7A98`).
- 공통 컴포넌트는 `ui/components/Components.kt`에 있다: 버튼, 아이콘 버튼, 기어 칩, 머리, 레일, 아래 탭, 두 숫자 카드, 작은 숫자, 기록 줄, 띠, 스위치 줄, 세그먼트, 토스트, 팝업, 스텝퍼, 해치, 말풍선.
- 첫 실행 A1~A4를 만들었다. A3는 마이크 권한을 요청한다. A4 목소리 시험은 세 번 중 두 번 들리면 통과한다. 두 번 못 들으면 "아무 말이나 예로 듣기"를 제안한다.
- 홈 C1(A5 준비 끝 포함)을 만들었다.
- 기록 저장소 `data/Store.kt`는 기기 안 JSON 파일 하나다.
- 차량 신호 게이트웨이 `vehicle/Signals.kt`와 음성 계층 `voice/Voice.kt`(TTS, STT, 합성 알림음, 대답 분류)를 만들었다.

**시험 결과.** `e2e/s1_onboard_home.py` 29개 항목이 모두 PASS다. 두 번 연속 돌려 두 번 다 통과했다(에뮬레이터 Pleos_Probe, 2026-11-07). `EXTRACTED`

**시험 중 고친 것.**

- 실제 버그 1건을 고쳤다. 앞 듣기를 멈춘 뒤 STT 종료 이벤트가 늦게 오면, 다음 듣기가 "못 들음"으로 끝날 수 있었다. 이제 이번 요청의 시작 이벤트를 본 뒤에만 종료를 받는다.
- 시험 쪽 버그 2건을 고쳤다.
  - 화면 읽기(약 2초) 때문에 4초 듣기 창을 놓쳤다. 시험이 "듣기 시작" 로그를 기다린 뒤 말하게 바꿨다.
  - 바탕색을 시스템 바 위치에서 읽었다. 앱 바탕 위치로 옮겼다.

**알게 된 것.**

- `EXTRACTED` 에뮬레이터에서 STT `request()` 뒤 `onStartedRecognition`이 오지 않는다. 마이크 입력이 없어서로 보인다(`INFERRED`). 실제 인식은 수동 시험에서 사람 목소리로 본다.
- `AMBIGUOUS` TTS 음량을 바꾸는 API는 문서에 없다. 설정의 목소리 크기는 알림음에만 적용한다.
